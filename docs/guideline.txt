## Purpose
- Represent each firm as a probability vector over 5 business structure patterns.
- Allow lifecycle transition (soft, not hard classification).
- PatternBonus is additive but capped (≤ 0.7σ).

## Input Features (all peer-group robust z-scores)
Growth: z_rev_cagr, z_ebit_cagr
Profitability: z_gross_margin, z_ebit_margin, z_roic
Cash Flow: z_fcf_conv, z_fcf_stability
Capital Intensity: z_capex_ratio, z_capex_growth
R&D: z_rd_ratio
Volatility: z_rev_vol, z_ebit_vol

## Raw Pattern Scores
1) Razor & Blade
Razor_raw = z_gross_margin + z_ebit_margin + z_fcf_conv + z_fcf_stability + 0.5 * z_rev_cagr
2) Commodity Cyclical
Commodity_raw = z_rev_vol + z_ebit_vol - z_fcf_stability
3) Platform Network Effect
Platform_raw = z_gross_margin + z_rev_cagr - z_capex_ratio + 0.5 * z_roic
4) High R&D Tech
RND_raw = z_rd_ratio + z_rev_cagr + z_roic
5) Capital Intensive Infra
Infra_raw = z_capex_ratio + z_capex_growth + 0.5 * z_rev_cagr

## Soft Classification
Step 1: Remove negative influence
Score_i = max(raw_i, 0)
Step 2: Normalize
If Σ Score_i > 0:
  P_i = Score_i / Σ Score_i
Else:
  P_i = 0.2  (equal probability)

## Pattern Bonus Weights
Razor      = +0.5σ
Platform   = +0.4σ
High R&D   = +0.3σ
Commodity  = 0
Infra      = 0

PatternBonus = Σ (P_i × Bonus_i)
PatternBonus capped: PatternBonus ≤ 0.7σ

## Final Integration

TotalScore = CoreScore + PatternBonus

Notes:
- Pattern influence intentionally limited (10–20% of total impact).
- Industry normalization applies only to CoreScore inputs.
- Pattern classification remains industry-agnostic.
- Designed for rolling multi-year backtesting.

  · Total Score: Total = Core + PatternBonus

Gross Margin = GrossProfit / Revenue
Operating Margin = OperatingIncome / Revenue
Net Margin = NetIncome / Revenue
ROE = NetIncome / Equity
ROA = NetIncome / Assets
FCF = CFO - CAPEX
Debt Ratio = Liabilities / Assets
